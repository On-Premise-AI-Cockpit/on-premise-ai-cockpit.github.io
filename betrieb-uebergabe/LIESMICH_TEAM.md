# Kurzanleitung für das Team — KI-Cockpit (100 % lokal)

## So nutzen Sie das Cockpit in 3 Schritten
1. Öffnen Sie die freigegebene Datei **`2026-11-18_cockpit_v1.0_stabil_offline.html`** per Doppelklick im Browser (Microsoft Edge, Chrome oder Firefox).
2. Ziehen Sie den aktuellen Monats-Export (`.csv` oder `.xlsx`) aus DATEV / HKR per Maus in das gestrichelte Feld (**Dropzone**).
3. Sämtliche Kennzahlen, Balken und Ampeln aktualisieren sich sofort lokal im Browser — keine Daten verlassen Ihren Dienstrechner.

## Wichtige Spielregeln
- Bitte speichern Sie Ihre Exporte nicht im Programm-Ordner, sondern in Ihrem normalen Fachordner.
- Änderungen an der Cockpit-Datei erfolgen ausschließlich durch die zwei benannten Pflege-Verantwortlichen; alte Stände liegen als Sicherung im Unterordner `/archiv/`.
